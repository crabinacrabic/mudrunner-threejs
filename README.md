# MudRunner Three.js - 3D Offroad Simulation in Browser

Этот проект вдохновлен:
1. Легендарным портфолио **Bruno Simon** (https://bruno-simon.com, репозиторий https://github.com/brunosimon/folio-2019) — изометрический вид, управление машиной, интерактивный мир на Three.js.
2. Играми **Spintires / MudRunner / SnowRunner** — продвинутая физика деформации грязи, колеи, сопротивление вязкого грунта, пробуксовка, блокировка дифференциала, пониженная передача и лебедка.

## Технологический стек
- **Three.js** (3D рендеринг, освещение, тени, шейдеры)
- **Web Audio API** (процедурный синтез звука дизельного двигателя, турбины и хлюпанья грязи без внешних файлов)
- **Dynamic Deformable Mesh** (динамическая сетка земли: колеса продавливают грязь и оставляют физическую колею в реальном времени)
- **Particle System** (комья грязи и брызги из-под колес при пробуксовке, выхлоп дизеля)

## Управление
- **W / Стрелка вверх**: Газ (акселератор)
- **S / Стрелка вниз**: Тормоз / Задний ход
- **A / D**: Поворот руля
- **Пробел (Space)**: Ручной тормоз
- **Q**: Переключение AWD (Полный привод 6x6)
- **E**: Переключение Diff Lock (Блокировка дифференциала)
- **R**: Пониженная передача (Low Gear)
- **F**: Лебедка (Winch) — зацепиться за ближайшее дерево и тянуть
- **C**: Смена камеры (Изометрия / От третьего лица / Сверху)
- **V**: Сбросить / перевернуть грузовик
- **M**: Звук вкл/выкл

## Запуск
Просто откройте файл `index.html` в Google Chrome или любом современном браузере.
