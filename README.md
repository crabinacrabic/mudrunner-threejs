# MudRunner Three.js - 3D Offroad Simulation in Browser

Этот проект вдохновлен:
1. Легендарным портфолио **Bruno Simon** (https://bruno-simon.com, репозиторий https://github.com/brunosimon/folio-2019) — изометрический вид, управление машиной, интерактивный мир на Three.js.
2. Играми **Spintires / MudRunner / SnowRunner** — продвинутая физика деформации грязи, колеи, сопротивление вязкого грунта, пробуксовка, блокировка дифференциала, пониженная передача и лебедка.

## Доступная техника (Выбор на клавиши 1-5)
1. **🚛 Тягач "Тайга-6x6"** — тяжелый лесовоз 6x6 с постоянным полным приводом, пониженной передачей, блокировкой дифференциала и 6 независимыми колесами.
2. **🚙 Джип 4x4 "Следопыт"** — детализированная 3D-модель внедорожника (Quaternius SUV) с экспедиционным багажником, канистрами и независимой подвеской.
3. **🚗 Седан "Классика"** — стилизованная 3D-модель легкового городского седана (Quaternius Car) с задним приводом и низким клиренсом.
4. **🚌 Ретро-Автобус "ПАЗ Турист"** — ретро-автобус со сдвоенными задними колесами для туризма по бездорожью.
5. **🏎️ Спорткупе "Racer GT"** — скоростное низкопрофильное спорткупе (Quaternius Sport) для скоростных заездов по асфальту и гравию.

## Технологический стек
- **Three.js + GLTFLoader** (3D рендеринг, освещение, тени, шейдеры и загрузка стилизованных низкополигональных 3D-моделей GLTF/GLB)
- **Web Audio API** (синтез звука дизеля ЯМЗ-238, турбонаддува, клаксонов и звуков грязи)
- **Dynamic Deformable Mesh** (динамическая сетка земли: колеса продавливают грязь и оставляют колею в реальном времени)
- **Particle System** (комья грязи и брызги из-под колес при пробуксовке, дым выхлопа)
- **3D Модели**: открытая библиотека low-poly моделей **Quaternius** (CC0 Public Domain)

## Управление
- **1, 2, 3, 4, 5**: Быстрое переключение автомобиля
- **W / Стрелка вверх**: Газ (акселератор)
- **S / Стрелка вниз**: Тормоз / Задний ход
- **A / D**: Поворот руля
- **Пробел (Space)**: Ручной тормоз
- **Q**: Переключение AWD (Полный привод)
- **E**: Переключение Diff Lock (Блокировка дифференциала)
- **R**: Пониженная передача (Low Gear)
- **F**: Лебедка (Winch) — зацепиться за ближайшее дерево и тянуть
- **C**: Смена камеры (Изометрия / От третьего лица / Сверху)
- **V**: Сбросить / перевернуть авто на старт
- **M**: Звук вкл/выкл

## Физика грунта, колея и налипание грязи
- Поле грунта 10 см на ячейку (`js/soil.js`): глубина колеи/валики, влажность, уплотнение, взбитая жижа. Колёса вдавливаются по давлению (модель Бекера-Вонга), вытесняют грунт в валики по бокам, уплотняют его; вода собирается в глубоких колеях.
- Тяга каждого колеса ограничена сцеплением с грунтом (кривая Янози): открытый дифференциал, блокировка (E), понижайка (R), узкие дорожные шины в грязи теряют сцепление.
- Грязь налипает на протектор в липком мокром грунте (глина, болото), забивает его и снижает сцепление; срывается центробежной силой, при пробуксовке и смывается в воде.
- Колея ведёт машину, днище ложится на горб между колеями, лебёдка (F) вытаскивает из болота.
- Рендер деформируемого грунта: `js/terrain_deform.js` (смещение вершин и попиксельные нормали колеи по текстуре поля).
