## 0. Главное, что нужно знать

**Сюжет официально утверждён (2026-10-19): «THE I.T. RUN» (Маршрут 3).**  
Игра посвящена перегону подержанных японских внедорожников в конце 1980-х — начале 1990-х годов:
- **Пролог**: Деревня Мутшатша (провинция Шаба / Катанга, Заир, координаты `-10.645, 24.459`). Молодой парень Мвепу продаёт семейный надел и на старом китайском дорожном велосипеде *Phoenix* добирается по глиняным тропам саванны до станции Мутшатша.
- **Путь на восток**: Поезд SNCC до Лубумбаши ➔ пеший переход границы в Касумбалесе ➔ монументальный китайско-африканский экспресс **TAZARA** (Нью-Капири-Мпоши ➔ Дар-эс-Салам, 1860 км).
- **Сделка**: Порт Дар-эс-Салам, покупка праворульной **Toyota Hilux 4x4 / Land Cruiser**, получение красных металлических транзитных номеров **«IT» (In Transit)**.
- **The I.T. Run**: Обратный многодневный оффроуд-перегон через Танзанию и Замбию в глубь Заира по рекам красного латерита до родной деревни.
- **Вдохновение**: *Spintires/MudRunner*, *art of rally*, *Over the Hill*, *Заря (Zarya)* и портфолио Bruno Simon.

## 1. Что существует как «игровая рамка» (факты из кода)

- **Формат**: тестовый полигон-«экспедиция» длиной 180 м, 7 секторов грунта, 7 контрольных ворот, таймер, финиш. Цель, как её видит игрок (подсказка в левой панели): «Цель экспедиции: пройдите все 7 контрольных ворот от старта до вершины Снежного перевала!».
- **Сектора** (`getSectorData` в `index.html`; знаки `createRoadSign`; границы по Z):

- **Контрольные точки** (`cpDefs`): z=−64 «КП-1: СТАРТ БЕТОН», −40 «КП-2: ТАЁЖНЫЙ ЛЕС», −15 «КП-3: ПЕСЧАНЫЙ КАРЬЕР», 12 «КП-4: ГЛИНЯНАЯ КОЛЕЯ», 36 «КП-5: ТОРФЯНОЕ БОЛОТО», 55 «КП-6: БРЕВЕНЧАТЫЙ МОСТ», 80 «🏁 ФИНИШ: ВЕРШИНА ПЕРЕВАЛА». Проход засчитывается при `|z − cp.z| < 3.6` и `|x| < 6.8`. Всплывающие сообщения (`showPopup`): «✅ ПРОЙДЕН КП-n (k/7)», на финише «🏆 ПОЛИГОН ПРОЙДЕН НА <ИМЯ МАШИНЫ>! ВРЕМЯ: мм:сс». Таймер экспедиции стартует при движении и идёт до финиша (`expeditionTime`, `expeditionFinished`); сброс — клавиша `V`.
- **Тон текстов**: русский, капслок в плашках, лёгкая «экспедиционная» лексика (топь, гать, перевал, лебёдка, понижайка), визуальные отсылки к Bruno Simon (изначальная вдохновляющая игра-портфолио) и к Spintires/MudRunner/SnowRunner (README).
- **Заголовок HUD**: «Полигон "Тайга"» + красная плашка «SNOWRUNNER» + подзаголовок «7 секторов грунта • 5 3D авто • Диорама в стиле Bruno Simon» (устарел: машин уже 10, стиль теперь Over the Hill — **тексты не обновлены, это кандидаты на правку вместе с сюжетом**).
- **Механики-«реплики» мира**: лебёдка `F` («ЛЕБЁДКА ЗАКРЕПЛЕНА ЗА ДЕРЕВО!» / «НЕТ ОПОРЫ ПОБЛИЗОСТИ ДЛЯ ЛЕБЁДКИ!»), блокировка дифференциала `E`, понижайка `R`, AWD `Q`, фары `L`, звук дизеля ЯМЗ-238 синтезируется Web Audio.

## 4. Точки расширения для сюжета (куда в коде вставлять повествование)

| Задача | Где |
|---|---|
| Названия/описания секторов, подписи знаков | `getSectorData` (поле `label`, `color`), вызовы `createRoadSign(z, title, desc)` |
| Контрольные точки, их тексты и количество | `cpDefs`, `.cp-dot` в HTML, `document.getElementById('cp-text')`, проверка в `animate()` («Проверка прохождения контрольных ворот») |
| Всплывающие реплики | `showPopup(text)` (`#hud-alert`, исчезает через 2.4 с) |
| Финал/награда/счёт | блок `if (cp.isFinish ...)` в `animate()`; `expeditionTime`; можно добавить экран результатов |
| Название и подзаголовок игры | `<title>`, `#header-bar h1` и `.subtitle`, плашка `.badge-tag` |
| Роль/биография машины | `vehicleConfigs[i]` (ru-названия, `badge`), `EXTRA_VEHICLE_SPECS[i].name/shortName/typeLabel` |
| Лор в подсказках | `#tips-panel` (HTML) |
| Новые карты/уровни | сейчас одна карта 80×180 м: рельеф и сектора задаются циклом высот и `soilTypeAt` / `getSectorData` (по Z); для нескольких карт потребуется вынести эти функции и палитру (`ovh*`) в данные уровня |
| Диалоги/NPC | механизма нет; можно сделать DOM-оверлей по аналогии с `#hud-alert` |

Требования: интерфейс на русском (пользователь русскоязычный), комментарии в коде — русские, идентификаторы — английские; уникальные имена глобалов в inline-скрипте; не ломать контракты `trees`, `getTerrainHeight`, `displaceAndMixWater` (см. `ФИЗИКА.md`, `ГРАФИКА.md`).

1. Как реализовать расчленение (отрыв рук) в Three.js
В Three.js персонажи анимируются через кости (`THREE.Bone`). Чтобы оторвать руку врагу или герою:

1. Разделение геометрии: Модель персонажа изначально должна быть разрезана на отдельные меши: туловище, плечо, предплечье, голова. Они привязываются к своим костям.
2. Триггер отрыва: При попадании пули или ударе мачете в конкретную кость (определяется через `THREE.Raycaster`), мы отвязываем этот меш от скелета (`Object3D.detach`).
3. Физика «тряпичной куклы» (Ragdoll): Оторванная конечность превращается в отдельный объект, которому задается импульс (скорость) в сторону удара, и включается гравитация, чтобы рука отлетала и падала на землю.
4. Кровавый фонтан: На месте отрыва спавнится `THREE.Points` (система частиц) ярко-красного цвета, которая брызжет в течение 1–2 секунд.

3. Быстрый набросок кода (Архитектура для стрельбы и частиц)
Для реализации эффектов тебе понадобятся базовые функции для пули и крови.
javascript

```
// 1. СТРУКТУРА ПУЛИ
const bullets = [];

function shoot(origin, direction) {
    const bulletGeom = new THREE.SphereGeometry(0.1, 8, 8);
    const bulletMat = new THREE.MeshBasicMaterial({ color: 0xffaa00 });
    const bullet = new THREE.Mesh(bulletGeom, bulletMat);
    
    bullet.position.copy(origin);
    bullet.velocity = direction.clone().multiplyScalar(2.0); // скорость полета
    
    scene.add(bullet);
    bullets.push(bullet);
}

// 2. СИСТЕМА КРОВИ (ЧАСТИЦЫ)
const bloodPool = [];

function spawnBlood(position) {
    const particleCount = 50;
    const geometry = new THREE.BufferGeometry();
    const positions = [];
    const velocities = [];

    for (let i = 0; i < particleCount; i++) {
        positions.push(position.x, position.y, position.z);
        // Разлет брызг в разные стороны
        velocities.push((Math.random() - 0.5) * 0.5, Math.random() * 0.5, (Math.random() - 0.5) * 0.5);
    }

    geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3));
    const material = new THREE.PointsMaterial({ color: 0x990000, size: 0.2 });
    const pSystem = new THREE.Points(geometry, material);
    
    pSystem.userData = { velocities, life: 1.0 }; // время жизни эффекта
    scene.add(pSystem);
    bloodPool.push(pSystem);
}

// 3. ИГРОВОЙ ЦИКЛ (ОБНОВЛЕНИЕ В АНИМАЦИИ)
function updateGame() {
    // Движение пуль
    bullets.forEach((b, index) => {
        b.position.add(b.velocity);
        
        // Проверка попадания (Raycast или по дистанции до кости врага)
        if (checkCollisionWithEnemyHand(b)) {
            let enemy = getEnemy(b);
            dismemberHand(enemy); // отрываем руку модели
            spawnBlood(b.position); // спавним кровь
            
            scene.remove(b);
            bullets.splice(index, 1);
        }
    });

    // Физика крови
    bloodPool.forEach((p, index) => {
        p.userData.life -= 0.02;
        if (p.userData.life <= 0) {
            scene.remove(p);
            bloodPool.splice(index, 1);
        } else {
            // Двигаем каждую каплю вниз (гравитация)
            const posAttr = p.geometry.attributes.position;
            for (let i = 0; i < posAttr.count; i++) {
                posAttr.setY(i, posAttr.getY(i) + p.userData.velocities[i*3 + 1]);
                p.userData.velocities[i*3 + 1] -= 0.01; // Гравитация
            }
            posAttr.needsUpdate = true;
        }
    });
}

```
